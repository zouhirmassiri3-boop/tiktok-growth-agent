# Trust & Social Proof Module — deeper reviews/before-after

A single 5-star card + a quote is one trust mechanism. Real buying decisions on a
COD product get made off several different ones stacked across a content run.
This module gives 8 distinct mechanisms, each a full ready post, to rotate into
the Morning (review) and Evening (before/after) slots in `CONTENT-CALENDAR-SEP.md`
alongside — not replacing — what's already there. Same rules apply: standalone
prompts, real avatar reference photos, TikTok safe-zone spec, dark-black-hair-
always, never invent a price/promo/stat.

**Why these 8 specifically:** each targets a different reason someone hesitates
to buy — "does it actually work," "is this fake," "will it work fast enough,"
"is it worth the money," "will my family think it's weird," "will it smell/make
a mess," "do people actually keep buying it," "is that a real person." Cover the
objection, you remove the hesitation.
